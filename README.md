# 🎬 API REST de Películas (Node + Express + MongoDB)

Pequeña API REST para gestionar películas usando **Node.js**, **Express** y **MongoDB/Mongoose**.


## Endpoints

| Método | Ruta | Descripción |
|--------|---------------------------|---------------------------|
| GET    | /api/movies               | Obtener todas las películas |
| GET    | /api/movies/:id           | Obtener una película por ID |
| POST   | /api/movies               | Crear una película |
| PUT    | /api/movies/:id           | Actualizar una película |
| DELETE | /api/movies/:id           | Borrar una película |


Se ejecuta com ```npm run dev```
